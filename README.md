# E-commerce Dashboard

> A modern and responsive e-commerce dashboard built with cutting-edge technologies

## 🚀 Features

- **Real-time Analytics** - Monitor sales, orders, and customer data
- **Product Management** - Add, edit, and manage your inventory
- **Order Tracking** - Complete order lifecycle management
- **User Management** - Customer and admin user controls
- **Responsive Design** - Works seamlessly on all devices
- **Dark/Light Mode** - Theme switching for better user experience

## 🛠️ Technologies Used

### Frontend

- **Next.js** - React framework for production
- **React** - UI library for building user interfaces
- **TypeScript** - Type-safe JavaScript
- **Shadcn/ui** - Beautifully designed components built with Radix UI and Tailwind CSS
- **Tailwind CSS** - Utility-first CSS framework
- **React Query v5** - Powerful data synchronization for React
- **Chart.js** - Data visualization

### Tools & Deployment

- **ESLint** - Code linting
- **Prettier** - Code formatting
- **Git** - Version control
- **Vercel** - Deployment platform

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Ahmed-Alabadla/Ecommerce-TrendHub-Dashboard.git

# Navigate to project directory
cd Ecommerce-TrendHub-Dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🔧 Environment Variables

Create a `.env` file in the root directory:

```env
# API Configuration
API_URL=your_api_url                    # Backend API base URL (server-side)
NEXT_PUBLIC_API_URL=your_api_url        # Backend API base URL (client-side)
NODE_ENV=development                    # Environment mode (development/production)

# E-commerce Integration
ECOMMERCE_URL=your_ecommerce_url        # Main e-commerce website URL (server-side)
NEXT_PUBLIC_ECOMMERCE_URL=your_ecommerce_url  # Main e-commerce website URL (client-side)
```

**Note:** Replace placeholder values with your actual URLs:

- `your_api_url` - Your backend API endpoint
- `your_ecommerce_url` - Your main e-commerce website URL
